# Lumine website

## Visual accuracy

Never use a fabricated Lumine editor view on this site. This includes HTML/CSS mockups, illustrations, reconstructed screenshots and AI-generated editor images. Any view of the application must be an authentic screenshot captured from running Lumine. When no suitable screenshot is available, use a text-based layout without an editor preview.

Keep the landing page within the viewport on ordinary desktop and mobile sizes. Preserve readable text and access to all main actions; do not hide overflow to disguise content that does not fit.
